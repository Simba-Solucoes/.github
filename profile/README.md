# Simba Soluções

Consultoria e software para bancos de dados geológicos em exploração mineral. Da coleta em campo ao controle de qualidade analítico, em um só fluxo, sem redigitação.

**[simbasolucoes.com.br](https://simbasolucoes.com.br)** · contato@simbasolucoes.com.br 

## Soluções

| Solução | Descrição | Repositório |
|---|---|---|
| **Simba DB** | Banco de dados geológico em nuvem, com acesso por cliente, auditoria, importação de laudos e exportações. | [simba-db](https://github.com/Simba-Solucoes/simba-db) |
| **Simba Field** | Aplicativo de coleta de dados geológicos em campo, offline, com validação na origem. | [simba-field](https://github.com/Simba-Solucoes/simba-field) |
| **Simba Valida** | Validação de cargas de dados geológicos contra o esquema do cliente. | [simba_valida_django](https://github.com/Simba-Solucoes/simba_valida_django) |
| **Simba Transform** | Conversão de dados geológicos sob medida (Excel, CSV, GeoPackage, DRX, susceptibilidade magnética). | [simba-transform](https://github.com/Simba-Solucoes/simba-transform) |
| **Simba Tags** | Geração de etiquetas com QR code para amostras. | [simba_tags](https://github.com/Simba-Solucoes/simba_tags) |
